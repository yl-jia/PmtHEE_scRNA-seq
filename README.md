# PmtHEE_scRNA-seq

## 1. Environment setup

- All the analysis based on R 4.4.1 and python 3.9.

- The Seurat used in this analysis is V4.4.
- Use Rstudio to open the .Rmd files in [Codes](https://github.com/yl-jia/PmtHEE_scRNA-seq/tree/main/Codes) folder.

## 2. File organization

There are 3 folders you need to reproduce my analysis:

- [Output_PDF](https://github.com/yl-jia/PmtHEE_scRNA-seq/tree/main/Output_PDF): the result pdf generated by me, as your ref.
- [Codes](https://github.com/yl-jia/PmtHEE_scRNA-seq/tree/main/Codes): All Rmd files I used for analysis, includes all codes I used. From 1 to 9, each file outputs will be named as R1, R2, R3...... R9 in output folder.
- [Input_data](https://drive.google.com/drive/folders/17QSWxK0bax-yKdBWhJUHiPa8yQZuTFbz?usp=sharing): On google drive, three Seurat objects to start your analysis.

## 3. PPT summary

Each figures with related file name, for example,

`R1_1_umap_cells.pdf`, means the file was generated by `1_old_combine_PmtHEE_FsEpi_FibHSE_by_seurat.Rmd`, where you can get all codes for reproducing the figure.
